# Akan name generator
## Project Overview
The Akan Name Generator is a web application that generates a user's traditonal Akan name based on their date of birth and gender. The Akan names originate from Ghana and are assigned to the day of the week on which a person in born.

## Features
Enter your birthday day,month, and year
Select your gender
Calculate the day of the week you were born
Display the corresponding Akan name.
Simple and user-friendly interface.
Responsive design for different screen sizes
